# AI — News Fetcher
AI - News Fetcher is a command-line Python tool that fetches the latest news using the NewsAPI service.
Users can enter their name and choose a topic, and the program returns the top 5 latest articles from the past 24 hours.

## ✨ Features
1.Fetches real-time news from NewsAPI

2.Shows top 5 latest articles with title, source, date, and link

3.CLI-based and easy to use

4.Automatically checks and loads API key using .env

5.Provides clear error messages if API key is missing or invalid
